# КИНОМАКС — Мобильная версия сайта кинотеатра

Мобильная версия веб-приложения для сети кинотеатров **«КИНОМАКС»** (Киномакс-Буревестник Владимир, пр. Ленина, д. 29), разработанная в точном соответствии с макетом Figma ([node-id=2047-2](https://www.figma.com/design/1z0l5x5qw0Brn5RMAM1gDX/Untitled?node-id=2047-2)).

---

## 📱 Особенности и реализованные экраны

- **Главный экран (Расписание)**:
  - Шапка кинотеатра с адресом и бейджами («Большой экран», «Лазерный RGB проектор»).
  - Фильтры по дням («Сегодня», «Завтра», «23 окт.») и форматам («Все», «2D», «Пушкинская карта»).
  - Карточки фильмов и быстрый переход к сеансам.
- **Боковое меню (Drawer)**:
  - Выдвижная шторка с быстрыми ссылками (Личный кабинет, Мои билеты) и категориями (КиноМиры, Афиша, Детям, Сертификаты).
- **Афиша**:
  - Каталог с фильтрами по жанрам (Концерты, Театр, Кино) и стартовыми ценами.
- **Поиск и фильтры**:
  - Поиск в реальном времени.
  - История поиска с возможностью удаления поисковых запросов.
  - Модальное окно фильтрации (Жанр, Дата, Диапазон цен).
- **Экран фильма («Битва моторов»)**:
  - Постер, возрастное ограничение (16+), хронометраж (2 ч 32 мин), жанры, синопсис.
  - Выбор даты и сеансов (09:40, 12:40, 13:50, 15:40) с ценами.
- **Выбор мест в зале (Схема зала)**:
  - Визуальная дуга киноэкрана («ЭКРАН»).
  - Интерактивная сетка мест (ряды 1–6, места 1–10).
  - Статусы мест: свободно, выбрано (малиновый акцент `#E52E84`), занято.
  - Динамический расчет стоимости билетов.
- **Оплата и бронирование**:
  - Выбор способа оплаты: сохраненная карта (`•••• 4242`), СБП, Apple Pay / SberPay.
  - Экран успеха («Готово!») с праздничным конфетти и автосохранением в купленные билеты.
- **Мои билеты**:
  - Карточки активных билетов с градиентами.
  - Модальное окно с QR-кодом для прохода в зал.
  - Функция возврата билета.
  - Экран истекшего билета.
- **Авторизация и профиль (Node 2047-2)**:
  - Экран входа («Вход») с плавающим уведомлением об ошибке («Неправильное имя пользователя или пароль»).
  - Вход через соцсети (Telegram, VK).
  - Регистрация с подсказкой надежности пароля.
  - Восстановление пароля: запрос $\rightarrow$ ввод 4-значного OTP-кода с таймером 45 сек $\rightarrow$ создание нового пароля $\rightarrow$ подтверждение смены.
  - Профиль пользователя («Иван Петров») и управление привязанными способами оплаты.

## 🚀 Запуск проекта локально

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev
```

## 📦 Сборка для GitHub Pages

```bash
# Сборка проекта
npm run build

# Деплой в ветку gh-pages
npm run deploy
```
